# Pendientes técnicos reales

Este archivo debe usarse solo para pendientes actuales, no para notas históricas de migración.

## Pruebas manuales pendientes

- Probar runtime completo con MySQL real después de cada bloque grande.
- Validar login y navegación por rol:
  - Administrador
  - Alumno
  - Coordinador de Prácticas
  - Coordinador de Unidades Receptoras
  - Unidad Receptora
  - Asesor Interno
  - Dirección

## Flujo operativo a validar

1. Registro público de empresa.
2. Aceptación/rechazo por Coordinación de Unidades Receptoras.
3. Carga y aprobación de documentos de empresa.
4. Convenio o vinculación.
5. Creación de vacantes.
6. Liberación a padrón empresarial.
7. Documentos de alumno.
8. Selección de vacantes por alumno.
9. Confirmación/asignación por coordinador.
10. Asignación de asesor interno.
11. Seguimiento de horas/reportes/evaluaciones.
12. Liberación final.
